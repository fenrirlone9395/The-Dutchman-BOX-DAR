# 公開文書の編集方針

READMEは現行の機能・使い方・制限、CHANGELOGは各版の変更点、技術資料は再現条件・測定方法・結果・限界を記載します。会話の転載や個人の作業日誌を公開文書に含めません。

- ファイル参照はリポジトリ相対パスを使用します。個人のホームディレクトリや添付ファイルの一時パスは記載しません。
- 機材は「USBオーディオインターフェース」「内蔵出力」など、検証に必要な分類へ一般化します。製品固有の互換性情報が必要な場合も、個人の所有環境と結び付けません。
- 端末名、デバイスUID、Aggregate UUID、シリアル番号、アカウント情報、私的な楽曲名や制作履歴は含めません。
- ログは必要部分だけを匿名化します。画面画像は機材表示、アカウント、ファイル名、通知なども確認します。
- 技術上必要なAPI名、標準形式名、ライセンス通知、再現用の合成データは保持します。測定値の意味や未確認事項を曖昧にしません。
- 過去の試験結果には対象版と条件を明記し、現行仕様・実機保証と混同させません。
- 未追跡の資料・ログを含め、公開する差分全体を確認します。

公開文書の編集と、アプリ識別子・権限・保存先の変更は別の作業です。既存インストールに影響する識別子は、文書の一般化だけを理由に変更しません。

## 機械チェック

```sh
python3 scripts/check-public-docs.py
```

追跡済み・未追跡の公開テキストを対象に、ローカルパスや未加工のデバイス識別子を検出します。機材の文脈、画像内の情報、文章の妥当性は検出しきれないため、目視査読も必要です。
