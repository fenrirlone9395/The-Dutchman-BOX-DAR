# 開発概要

本資料は実装段階の概要です。各版の変更は[CHANGELOG](../CHANGELOG.md)、現行の使い方・制限は[README](../README.md)を参照してください。

| 段階 | 主な内容 |
|---|---|
| 初期キャプチャ | macOSの音声取得、ステレオ出力、ミュート、デバイス選択 |
| 内蔵DSP | ゲイン、EQ、サンプルピークLimiter、入力・出力メーター |
| AUホスト | AUv2、メーカーGUI、プリセット、再生中のラック編集 |
| ラックUI | 8枠表示、フローティングパネル、ゲインノブ、プリセット状態表示 |
| Spatial | 角度・距離・量で操作するCrossfeed。HRTFとは別の処理 |
| Clock/Rate Adapter | Legacy、Direct、Fixed、Asyncの分離とオフライン比較 |
| VST3ホスト | ステレオEffect、GUI、補助バス互換性、別プロセスのスキャン |
| 保存と固定枠 | 内蔵設定を含む保存、空き位置の保持、枠の交換 |
| 一覧キャッシュ | 起動時の候補表示、差分スキャン、手動の全件再スキャン |
| 復旧処理 | 再priming時の制御状態リセットとイベント観測 |

## 検証の位置付け

自動テストは合成入力、テスト用プロセッサ、標準AUを中心に実行します。第三者プラグインでの動作確認は、同じ形式の全製品に対する互換性保証ではありません。

Clock/Rate Adapterの測定資料は測定時点の版に対する記録です。現在の既定モードや復旧動作と異なる記載は、資料内の対象版・更新注記と合わせて参照してください。実デバイスの経路全体については、オフラインのbit-exact結果だけで透明性を断定しません。

HRTF、LCR展開、True Peak処理などの検討は、現行の実装済み機能とは区別します。
